# Changelog

## 0.1.0 - 2026-07-13

### Added

- Professional responsive styling across home, shop, about, contact, navbar, and footer.
- Editorial blog section on the homepage with featured and compact post layouts.
- Product-specific generated images for all shop products.
- Shop pagination with visible active page, previous/next controls, and page clamping.
- Richer About and Contact page content.
- Netlify configuration with SPA redirect support.

### Changed

- Reorganized styles into `src/styles`.
- Replaced stale Create React App README content with project-specific documentation.
- Pinned `react-router-dom` to v6 to match the app's routing API.
- Cleaned public metadata in `public/index.html`.

### Removed

- Unused CRA manifest references and stale public assets.
- Unused product placeholder images.
- Unused dependencies and unused starter files.
